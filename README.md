# PollMaster - Веб-приложение для создания и проведения опросов

## Описание проекта

PollMaster - это полнофункциональное веб-приложение, позволяющее пользователям создавать опросы, голосовать, оставлять комментарии и анализировать результаты в виде графиков. Проект разработан в рамках учебного курса по веб-технологиям.

## Технологии

- **Backend**: Python 3.10+, Flask
- **ORM**: SQLAlchemy
- **База данных**: SQLite
- **Frontend**: Bootstrap 5, HTML5, JavaScript, jQuery
- **Графики**: Chart.js
- **API**: RESTful

## Функциональность

### Для всех пользователей
- Просмотр списка активных опросов
- Просмотр опросов и вариантов ответов
- Просмотр статистики и графиков результатов
- Поиск опросов

### Для зарегистрированных пользователей
- Регистрация и авторизация
- Загрузка аватара профиля
- Создание опросов с изображением-обложкой
- Добавление нескольких вопросов (одиночный/множественный выбор)
- Голосование в опросах
- Оставление комментариев
- Просмотр своих опросов
- Редактирование и удаление своих опросов
- Копирование (клон) опросов
- Экспорт результатов в CSV и JSON

### Для администратора
- Просмотр всех пользователей
- Блокировка/разблокировка пользователей
- Просмотр всех опросов
- Удаление комментариев
- Очистка старых неактивных опросов

### API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/polls` | Получить список всех опросов |
| GET | `/api/poll/<id>` | Получить данные опроса |
| POST | `/api/vote/<id>` | Проголосовать в опросе |
| POST | `/api/comment/<id>` | Оставить комментарий |
| DELETE | `/api/comment/delete/<id>` | Удалить комментарий (админ) |
| GET | `/api/stats/<id>` | Получить статистику опроса |
| GET | `/api/user/polls` | Опросы текущего пользователя |
| GET | `/api/global-stats` | Глобальная статистика |
| GET | `/api/random-poll` | Случайный опрос |
| GET | `/api/has-voted/<id>` | Проверить, голосовал ли пользователь |
| GET | `/api/recent-polls` | Последние 5 опросов |
| GET | `/api/comments/<id>` | Комментарии к опросу |
| GET | `/api/search?q=` | Поиск опросов |
